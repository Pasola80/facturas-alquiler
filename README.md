# Facturas de alquiler

Programa para Windows que prepara cada mes las facturas de alquiler en PDF y envía los correos desde Outlook.

- **1. Preparar las facturas:** crea los PDF del mes con la numeración que sigue.
- **2. Enviar los correos:** cada factura va por correo al arrendatario, y una copia aparte a quien se indique.

## Uso
1. Descarga `Facturas-de-alquiler.exe` desde la sección **Releases** de este repositorio.
2. Cópialo en una carpeta junto a tu `config.json` (los datos personales no están aquí).
3. Doble clic en el `.exe`. La primera vez Windows puede avisar con «Windows protegió su equipo»: pulsa «Más información» y «Ejecutar de todas formas».

`config.ejemplo.json` muestra el formato del archivo de datos, con datos inventados.
